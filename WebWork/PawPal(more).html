Challenges

Developing a website with someone else at the same time had a series of challenges. Agreeing on ideas, what each other should code, and especially coding at the same time. If we were to code at the same time and accidentally altered something on one of the pages without knowing, we would have to pin point the exact mistake to try and save the code as a whole. Sometimes I would make comments on things I worked on that would make more sense for me and not my teammate, and the same way would go for them.
